Petunjuk Singkat Google Apps Script:

  1. Buat Google Sheet baru
  2. Klik Extentions > Apps Script
  3. Buat fungsi `doPost(e)` untuk appendRow ke Sheet
  4. Deploy sebagai Web App (Anyone / Siapa Saja)
